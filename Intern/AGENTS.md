# Intern 协作入口

本文件是阅读索引。**项目核心约束维护在 `docs/`，执行任务前必须按下表阅读适用文档并遵循其中要求。** 产品介绍和使用入口见 [README.md](README.md)。

| 要了解或执行什么 | 必须阅读的位置 |
| --- | --- |
| 产品范围、路线、技术选型、共享架构与恢复边界 | [docs/roadmap/数据库备份与恢复-2026-10-17.md](docs/roadmap/数据库备份与恢复-2026-10-17.md)；后续功能路线从 [docs/README.md](docs/README.md) 查找 |
| 修改代码、复用组件、处理 CLI/Web/base 边界 | [docs/guide/development.md](docs/guide/development.md) |
| 选择检查范围、执行真实组件测试、判断能否验收 | [docs/guide/quality.md](docs/guide/quality.md)；产品矩阵细节见路线文档第 15 节 |
| 新增或修改功能、排障、拆分任务、记录交付 | [docs/workflow/issue.md](docs/workflow/issue.md) |
| 暂存、提交、准备 PR、汇总 Issue 验收 | [docs/workflow/pr.md](docs/workflow/pr.md) |
| 新增或迁移文档、命名路线、解决文档冲突 | [docs/guide/documentation.md](docs/guide/documentation.md) |

所有任务先读产品路线与适用 guide；涉及功能变更时先落实对应 GitHub Issue，再按 Issue/PR 流程推进。纯文档整理按文档规范和对应流程检查。未决方案与未验证内容保持明确状态。

完整目录与维护职责见 [docs/README.md](docs/README.md)。原 [prd.md](prd.md) 仅保留迁移入口，不再维护另一份方案；Claude 的入口见 [CLAUDE.md](CLAUDE.md)。
